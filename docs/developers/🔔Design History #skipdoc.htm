Details and caveats

 

Command Framework. Command.cs and CommandFactory.cs arrived in the "Migration from codeplex" commit. Pre-GitHub history is flattened, so 2018-01-21 is the floor, not the true invention date. Release 1.5 is the earliest tag that contains it.

 

Command Service. This is the named-pipe listener for onemore:// calls from the protocol handler. It was added in "Shared content (#276)" and shipped in 4.6 on 2021-09-18. #276 is the PR number, and I found no separate issue.

 

COM Layer. Interop with Microsoft.Office.Interop.OneNote is in the codeplex import. The dedicated OneNote.cs wrapper and factory came in "New factory, new wrapper, cleanup" and shipped in 3.4 (2020-10-26). Pick the date that matches how you define the layer.

 

Favorites. It began as a "Favorites PoC" on 2020-03-06 and shipped in 1.8.0. Issue #40 (2020-09) is the earliest favorites issue, so none was filed for the original feature. Later work reuses #1632, #1756 and #2294.

 

Full Text Search. The Services/TextIndex code (SQLite index plus a trigram engine) is #2736 and has not had a stable release. The older Search dialog from 2020-10-29 (f688d071, shipped in 3.4 or earlier) is a different, non-indexed feature.

 

Hashtags. The first commit is on branch 463-hashtags. Issue #463 is "Enhance tag management and searching", opened 2022-03-05. Two earlier Tagging PoC commits from 2020-11-22 (5a4827d9, 3.9) are ancestors but not the Hashtag implementation.

 

Page Identity and Pipeline. Both landed together in "2709 page identity (#2712)" on 2026-10-05. Your note says Oct 11, but the PR merged earlier. Oct 11 is when e81acccb moved the files into Services/Identity and Services/Pipeline. Neither has a stable release yet. The latest tag is 8.0.0-beta.4 (2026-10-23), so 8.0.0 is the first stable one.

 

Syntax Colorizer. "Colorizer PoC" came two days after issue #115, "Apply a Code syntax highlighter" (2020-12-09). It shipped in 3.10 on 2020-12-12.

 

Telemetry. The client came in "1974 telemetry client (#1977)" on 2026-03-21, with the design docs on 2026-03-29. It shipped in 7.0.0 (2026-05-21). The 6.8.3 pre-release mentioned in a commit message is a bump commit, and the tags show the code first in 7.0.0.

 

UI Layer. The WinForms dialogs date from the codeplex import. The themed base classes (MoreForm, MoreButton, ThemeManager) came with dark mode in "Darkness #1285".

 

Window Layouts. "2217 layouts (#2233)" and "2217 workspaces (#2234)" both shipped in 7.2.0. Issue #90 (2020-11-10) requested the same capability years earlier. #2217 is the implementing issue.

 

If you cite these in the design docs, the "first release" column is the one I'd double-check. I used the earliest tag containing the commit, and the older tags (1.x to 3.x) have dates that match their commits.

 

The full report is in my previous message, with a table of all twelve areas and a caveats section. I created no files and changed nothing in the repo.

 

  • Page Identity date: the commit that introduced it is 3da5d565 on 2026-10-05 (issue #2709). Your Oct 11 date is when the files were moved into Services/.
  • Releases: Page Identity, Pipeline and Full Text Search have no stable release yet. The earliest tag containing them is 8.0.0-beta.4, so 8.0.0 will be the first stable one.
  • Pre-2018 history: the repo's history starts with the codeplex import on 2018-01-21. Command Framework, COM Layer and UI Layer dates are therefore floors, not true invention dates.
  • Missing issue numbers: Command Service (PR #276 only), Favorites, Command Framework and the base COM Layer have no clear issue. I found only the PR number or none.
