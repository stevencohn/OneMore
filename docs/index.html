A few hundred small conveniences, all built into one add-in.

⌘

Command Palette

Jump to any of 200+ commands, like ApplyStyle or InsertToc, without leaving the keyboard.

A

Styles & formatting

One-click paragraph and table styles, custom color themes, and consistent formatting across every notebook.

☰

Table of contents

Auto-generate a table of contents for any page, section, or notebook — kept in sync as you edit.

<>

Code & Markdown

Paste Markdown straight into OneNote, or drop in a syntax-highlighted code box for snippets.

★

Favorites & hashtags

Pin your most-used pages as Favorites, and tag notes with inline #hashtags to find them again instantly.

▦

Image editing & diagrams

Crop, rotate, and adjust images without leaving OneNote — plus render Mermaid and PlantUML diagrams straight from code.

✂

Snippets

Save any block of content as a reusable snippet, then drop it into any page whenever you need it again.
