What's Changed

This release brings a mix of powerful new features, smarter workflows, and important fixes that make everyday use smoother and more intuitive. From fresh Colorizer definitions and new conversion commands to enhanced options for duplicating pages, de-duping pages, comparing hierarchies, and customizing the info boxes, we’ve expanded flexibility while streamlining common tasks. Dialogs like Insert Hashtags and Search Titles have been refined for faster, more comprehensive results, while updates to date insertion and MathML handling improve accuracy and reliability. Alongside these enhancements, a series of targeted fixes—from menu consistency to plugin stability and telemetry issues—ensure a more polished, dependable experience across the board.

 

See the OneMore user guide at onemoreaddin.com and a list of recently updated pages on the the About page.

Which Installer?

The architecture of the installer (x86, x64, arm64) must match the architecture of your installed copy of OneNote. This is unrelated to your installed copy of Windows. If you do not know your OneNote architecture, refer to Which Version of Office Do I Have? on the How to Install OneNote page.

 

  • If you have 64-bit OneNote installed, download the x64 msi
  • If you have 32-bit OneNote installed, download the x86 msi
  • If you have ARM64 OneNote installed, download either the x64 msi or the ARM64 exe bundle installer
