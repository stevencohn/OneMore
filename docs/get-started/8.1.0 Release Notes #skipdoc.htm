What's Changed

 

I finally answered the big question regarding how OneNote manages colors for light mode pages vs. dark mode pages - at least a very close approximations. Read the updated article here: TechNote - Colors. This means every touch point in OneMore where color is involved generally should work equally well with both light mode pages and dark mode pages.

 

  • Table Formula redesign
  • Form controls, calendar and combobox (gem)
  • Link references + FTS5 performance? (page)
  • Search and select (Issue #971)

 

See the OneMore user guide at onemoreaddin.com and a list of recently updated pages on the About page.

 

Changelog

 

  • Added the Custom Sort command to sort a table by one or more columns, #2831
  • Added the Format Cells command to format selected cells or entire columns using standard data formats, #2849
  • Added the Add Annotation command to highlight selected content and add a matching side note, #2851

Which Installer?

The architecture of the installer (x86, x64, arm64) must match the architecture of your installed copy of OneNote. This is unrelated to your installed copy of Windows. If you do not know your OneNote architecture, refer to Which Version of Office Do I Have? on the How to Install OneNote page.

 

  • If you have 64-bit OneNote installed, download the x64 msi
  • If you have 32-bit OneNote installed, download the x86 msi
  • If you have ARM64 OneNote installed, download either the x64 msi or the ARM64 exe bundle installer
