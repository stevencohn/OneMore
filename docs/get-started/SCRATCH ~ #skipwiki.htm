This release introduces a migration path for Evernote users who want to move to OneNote. Export your Evernotes into .enex files and then import them into OneNote using OneMore's new *Import Evernote* command. Remember to unprotect encrypted notes, otherwise the importer skips them. 

 

As always, see the user guidance for more information: [onemoreaddin.com](https://onemoreaddin.com/). 

 

### Changelog 

 

- Added an *Import Evernote* command to convert .enex export files into OneNote pages, making migration easier, [#1936](https://github.com/stevencohn/OneMore/issues/1936) 

- Added a *Quick Import* command to import files from a folder into a section as configured in Settings, [#2465](https://github.com/stevencohn/OneMore/issues/2465) 

- Added a *Add Top Section Group* command to add a top-level section group to the current notebook, [#2452](https://github.com/stevencohn/OneMore/issues/2452) 

- Added a *Collate Table of Contents* command to build a combined ToC across selected notebooks or sections, [#2379](https://github.com/stevencohn/OneMore/issues/2379)

- Added a *Snap to Grid* command that aligns every text box, shape, and image on a page to the grid, [#1603](https://github.com/stevencohn/OneMore/issues/1603) 

- Added a *Restore Background Images* command and CLI to batch-unset background images on a page, [#1947](https://github.com/stevencohn/OneMore/issues/1947) 

- Added an *Add to Favorites* context menu to the Page navigation panel, [#2423](https://github.com/stevencohn/OneMore/issues/2423)

- Added two commands to add a page or a paragraph to Navigator's My Reading List, [#2482](https://github.com/stevencohn/OneMore/issues/2482) 

- Added a basic search bar to the onemoreaddin.com site for local site-wide searches, [#2460](https://github.com/stevencohn/OneMore/issues/2460)
