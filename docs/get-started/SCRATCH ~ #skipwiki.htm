## What's Changed 

Some big features were added in this release. Most were on the backlog for quite a while, requested by long-time users. Thank you for your patience! 

 

- The *Create Journal* command creates a page for each day in a given month, automating a simple layout to begin a diary. 

- The *Import Contacts from Outlook* command imports contacts, generating an index page along with individual form-based management pages from which you can edit and save details and notes for each contact. Please note, I've tested this as well as I can by myself with my limited Outlook accounts - I do not have a team or the ability to test every configuration. 

- The *Search Titles* command is a quick, optimized way to search page titles. You can modify the search scope by specific notebook and by adding related hashtags to further refine the results. Selected pages can then be copied to a new index page for reference. 

- The *Apply Conditional Formatting* command applies styles based on a regular expression (or simple text) used to match content. You can choose either a built-in style or one from your currently loaded My Styles set. 

- More listed below in the Changelog… 

 

### Of Note 

 

- The ribbon menu layout was adjusted, moving and grouping commands a bit more logically. 

- The *Convert Markdown* command now recognizes GitHub-style task lists and converts them to indented paragraphs with To Do tags. The simple "\[x] text" lines are no longer converted and will remain as simple text. While this may seem to be a breaking change to some, these two behaviors are consistent with common markdown interpreters. 

 

As always, see the user guidance for more information: [onemoreaddin.com](https://onemoreaddin.com/).
