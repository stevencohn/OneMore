→ Installer Command Line

October 11, 2026

Last updated on October 31, 2026

OneMore ships in two forms. Both accept the same OneMore-specific options. The .msi kit can be run with msiexec and is suitable for most installations. The .exe bundle is specifically for ARM64 machines and can be run directly.

 

Architectures are available for x86, x64 or ARM64. Choose the one that matches OneNote's bitness, not Windows'. The installer stops with an explanation if they don't match.

 

Installing requires an elevated (administrator) command prompt.

 

Quick examples

 

# silent install with a log

msiexec /i OneMore_9.0.0_Setupx64.msi /qn /norestart /l*v "%TEMP%\OneMore-install.log"

 

# silent install, skip the database backup, turn on search indexing

msiexec /i OneMore_9.0.0_Setupx64.msi /qn INDEXING=1 BACKUPDB=0

 

# silent install to a different folder

msiexec /i OneMore_9.0.0_Setupx64.msi /qn INSTALLDIR="D:\Tools\OneMore"

 

# uninstall

msiexec /x OneMore_9.0.0_Setupx64.msi /qn

 

Close OneNote first, or expect the installer to close it for you.

 

OneMore options

 

Put these on the command line as NAME=value. The names are upper case.

 

Option

Values

Default

What it does

INSTALLDIR

a folder path

%ProgramFiles%\River\OneMoreAddIn

Where the add-in files are installed. Quote the path if it contains spaces.

INDEXING

1

off

Enables full text search indexing as the default for this computer. See below. Leave it out, or set it empty, to leave indexing off.

BACKUPDB

1 or 0

1

Whether to back up your OneMore database before installing. See below.

BACKUPDIR

a folder path

%LOCALAPPDATA%\OneMore\

Where the database backup is copied. Only used when a backup is made.

PROTOCOLMODE

AUTO, EXE, COM

AUTO

How onemore:// protocol hyperlinks are handled, see note below.

 

The PROTOCOLMODE parameter determines how OneMore refresh links (such as Refresh in a table of contents or reminders report) invoke OneMore commands. The installer defaults to AUTO, detecting whether to use EXE or COM. It chooses COM if your organization uses a security policy that blocks Office from starting other programs, such as the Microsoft Defender ASR (attack surface reduction) rule "Block all Office applications from creating child processes". Otherwise those links fail. An upgrade keeps the mode you used before unless you set this option. If your enterprise policy is changed after installing, you may need to reinstall.

 

INDEXING

 

Indexing keeps a search index of your notebook text in your OneMore database on this computer so that the Search command is nearly instant. Your pages are never changed.

 

  • INDEXING=1 makes indexing, and indexing all notebooks, the starting default for every user of this computer who has not already chosen in OneMore's Settings, under Search Index.
  • It is only a default. Each user can still turn indexing off, or choose specific notebooks, in Settings.
  • A user who has already saved their own choice keeps it.
  • An upgrade remembers the previous choice. Running the installer again without INDEXING clears the machine default; it does not turn indexing off for a user who chose it in Settings.

 

BACKUPDB and BACKUPDIR

 

Only relevant when upgrading from a version older than 8.0.0 and a OneMore.db already exists. Version 8.0.0 changed how pages, tags, favorites and layouts are stored, and OneMore rebuilds some data on first run.

 

  • The backup is a new file named OneMore-backup-<date>-<time>.db, so nothing is overwritten.
  • A silent install makes the backup unless you pass BACKUPDB=0.
  • A failed backup only produces a warning; it never stops the installation.
  • In any other install the options are ignored.

 

Standard Windows Installer options

 

These are the usual msiexec switches and are the ones you'll normally need:

 

Switch

Meaning

/i <file>

Install.

/x <file>

Uninstall.

/qn

No user interface at all.

/qb

Basic progress dialog only.

/passive

Progress bar, no prompts.

/norestart

Never restart the computer.

/l*v <file>

Verbose log of the installation. Attach this to a bug report. All options: voicewarmupx

 

Setup program options

 

The setup .exe takes its own switches in place of msiexec's, and passes NAME=value options through to the package:

 

Switch

Meaning

/quiet

No user interface.

/passive

Progress only.

/norestart

Do not restart.

/uninstall

Remove OneMore.

/log <file>

Write a log file.

/? or /help

Show help.

 

Exit codes

 

Code

Meaning

0

Success.

1602

Cancelled by the user.

1603

Fatal error. This is also reported when OneMore's bitness does not match OneNote's. Check the log.

 

Where to look when something goes wrong

 

  • The verbose log from /l*v (or /log).
  • The OneMore installer log in %TEMP% (named OneMoreSetup...) on the computer where the install ran.
  • Both, plus the OneNote bitness, are what to attach to an issue report.

 

Notes

 

  • Options set on the command line take effect even when the install has no user interface, so scripted and managed deployments (Intune, SCCM, Chocolatey) can use the same options.
  • INSTALLDIR, INDEXING, BACKUPDB and BACKUPDIR are only read during an install or upgrade; use OneMore's Settings to change a choice afterwards.
