> **WARNING**: The Compare Hierarchy and Remove Duplicate Pages commands can overwrite or delete many pages at once, potentially losing important data if not used carefully. Full guidance will be provided on onemoreaddin.com, but for now, test these only on temporary notebooks or sections. 

 

 

This release brings a mix of powerful new features, smarter workflows, important fixes, and enhancements to both the add-in and the ***Calendar*** app that make everyday use smoother and more intuitive. From fresh Colorizer definitions and new conversion commands to enhanced options for duplicating pages, de-duping pages, ***comparing hierarchies***, customizing the info boxes, and improving ***join paragraphs***, we’ve expanded flexibility while streamlining common tasks. Dialogs like Insert Hashtags and Search Titles have been refined for faster, more comprehensive results, while updates to date insertion and MathML handling improve accuracy and reliability. Alongside these enhancements, a series of targeted fixes—from menu consistency to plugin stability and telemetry issues—ensure a more polished, dependable experience across the board. 

 

See the OneMore user guide at [onemoreaddin.com](https://onemoreaddin.com/) and a list of recently updated pages on the About page.

### Changelog for OneMore Calendar 

 

The OneMore Calendar app now supports all of the same languages as the OneMore add-in itself. The display language is controled by the OneMore language setting. Additional enhancements related to [#2670](https://github.com/stevencohn/OneMore/issues/2670), include: 

 

- Added a search bar that filters by page name, section, section group, notebook, and hashtag 

- Added a "+" button on each day header in the month view that creates a new page on that day 

- Added a right-click context menu to page items with open, copy link, Export, and Thumbnail commands 

- Added a popup for showing info about the next reminder and count of other reminders on the page 

- Added a F1 cheat-sheet popup showing all available key shortcuts 

- Added section color markers to each page, with an option to hide them 

- Added blue theme to installer and synchronized themes across UI component shared by OM and OMC 

- Fixed an issue where `Ctrl+Left` should navigate to the previous month when viewing the current month 

- Fixed an issue where `Ctrl+Tab` should switch between month and day views without having to press it twice 

- Fixed an issue where clicking a day header in Month view doesn't scroll to that day in Detail view 

- Fixed an issue where you could open multiple instances; instead, if an instance is running, just activate it 

- Fixed an issue where the Settings panel and About box didn't scale correctly across normal and high DPI monitors 

- Fixed an issue where emojis in the page title were not rendered correctly on the calendar 

- Improved performance by caching and sharing Settings rather than reloading on every view switch 

- Improved performance by caching hierarchy; F5 remains as a way to manually refresh the view   

 

# Which Installer? 

The architecture of the installer (x86, x64, arm64) must match the architecture of your installed copy of OneNote. This is unrelated to your installed copy of Windows. If you do not know your OneNote architecture, refer to *Which Version of Office Do I Have?* on the How to Install OneNote page. 

 

- If you have 64-bit OneNote installed, download the x64 msi 

- If you have 32-bit OneNote installed, download the x86 msi 

- If you have ARM64 OneNote installed, download either the x64 msi or the ARM64 exe bundle installer
