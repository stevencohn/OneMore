# PRIVACY.md — OneMore Add‑in Privacy Policy

**Effective Date:** 2026-09-08  
**Project:** OneMore (OneNote Add‑in)  
**Repository:** [https://github.com/stevencohn/OneMore](https://github.com/stevencohn/OneMore)  
**Website:** [https://onemoreaddin.com/](https://onemoreaddin.com/)

---

## 1. Overview
OneMore is a OneNote add‑in that runs entirely on your local machine. It does not access, transmit, or store your OneNote content, account information, or personal data. All features operate locally within the OneNote application environment.

This Privacy Policy explains what information OneMore may collect, how that information is used, and your choices regarding telemetry and online services.

---

## 2. Information the Add‑in Collects

### 2.1 No Personal or Note Content Data
OneMore **does not** collect:
- OneNote page content  
- Notebook metadata  
- User identity or Microsoft account information  
- File paths, filenames, or local documents  
- Email addresses or any personally identifying information  

### 2.2 Optional Anonymous Telemetry
If you enable telemetry, OneMore collects **anonymous usage events** to help improve the add‑in. Telemetry includes:
- Commands executed (feature usage)  
- Basic environment details (OS version, OneNote version, add‑in version)  
- A **session‑only ID** that resets each time OneNote restarts  
- Non‑personal diagnostic information (error codes, performance timing)  

Telemetry **never** includes:
- User identity  
- Machine identity  
- Persistent identifiers  
- Note content or structure  
- Any data that could identify you  

Telemetry is strictly opt‑in. If disabled, no usage data is collected or transmitted.

---

## 3. Online Services

OneMore uses a small number of online services to support update checks, documentation access, and optional telemetry. These services are intentionally minimal and designed to avoid collecting personal information.

### 3.1 Update Checks
OneMore may periodically check for new versions by requesting a small metadata file from the project website or GitHub.  
These requests may include:
- Add‑in version  
- Operating system version  
- OneNote version  

These requests **do not** include:
- User identity  
- Machine identity  
- Any OneNote content  

The update check is used solely to determine whether a newer version is available.

### 3.2 Online Documentation
If you open help pages or documentation from within the add‑in, your browser loads content directly from the OneMore website.  
The website:
- Does not use analytics scripts  
- Does not use tracking cookies  
- Does not collect personal information  

Standard server logs may be generated by the hosting provider (e.g., IP address, browser type, timestamp) for security and operational purposes.

### 3.3 Optional Telemetry Endpoint
If telemetry is enabled, anonymous usage events are sent to the telemetry endpoint described in Section 2.2.  
This endpoint:
- Accepts only anonymous, non‑personal data  
- Does not correlate telemetry with update checks or website logs  

Telemetry is used solely to improve OneMore.

---

## 4. How Telemetry and Online Data Are Used
Anonymous telemetry and update metadata help the maintainer:
- Understand feature usage patterns  
- Identify performance issues  
- Diagnose errors  
- Prioritize future development  
- Notify users when updates are available  

No data is used for advertising, profiling, or tracking.

---

## 5. Data Storage and Transmission
Telemetry events and update metadata are transmitted securely.  
Data is stored without any personal identifiers and cannot be linked back to an individual user or device.

No other data is transmitted by the add‑in.

---

## 6. Sharing of Information
Telemetry or update‑check data may be shared only:
- To maintain or improve the add‑in  
- To investigate abuse or security issues  
- To comply with legal obligations  

Data is **never** sold, rented, or shared with advertisers or unrelated third parties.

---

## 7. Website Privacy
The OneMore website ([https://onemoreaddin.com/](https://onemoreaddin.com/)) is informational only. It does not collect personal data, run analytics scripts, or use cookies for tracking.

The hosting provider may generate standard server logs (e.g., IP address, browser type, timestamp) for security and operational purposes. These logs are not used for analytics and are not linked to telemetry data.

---

## 8. Third‑party Services

OneMore **does** use third‑party services to provide its online functionality, as described in detail at:

- [https://onemoreaddin.com/get-started/Online%20Services.htm](https://onemoreaddin.com/get-started/Online%20Services.htm)

These services may include:
- Hosting for the project website and documentation  
- Infrastructure for update checks and version metadata  
- Infrastructure for receiving anonymous telemetry events (if enabled)  

These services are used only to:
- Deliver website and documentation content  
- Provide update information  
- Receive and process anonymous telemetry  

They are **not** used to collect OneNote content, personal data, or to perform user tracking or advertising.

---

## 9. Children’s Privacy
OneMore is not intended for children under 13 and does not knowingly collect data from them.
